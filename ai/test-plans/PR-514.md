# Test Plan — PR #514: OpenRouter backend via existing OpenAIClient (#507)

- **PR:** #514, branch `feat/507-openrouter-backend`, head `c15eb14`
- **Linked issue:** #507
- **Author role:** engineering
- **Plan author:** test-design role (rfc-test-design-agent), 2026-06-12
- **Constraint:** NO live API calls anywhere — no OpenRouter key exists; all

  execution.

## Intent check

Issue #507 scope vs diff:

1. `.env` + config provider entries → `.env.example`, `config/local_models.yaml`
   `providers:` section, `src/rfc/providers.py` (`load_providers`,
   `resolve_api_key`). **Covered.**
2. Free-pool discovery via `/models`, filter `:free`, rotate within
   1,000/day + 20 RPM → `discover_free_models`,
   `select_models_within_budget`, RPM pacing in `run_provider_suites`.
   **Covered** (budget is an upfront estimate-based cap, not a runtime
   request counter — see case B4).
3. Per-provider 429/backoff, skip-and-log → `src/rfc/retry.py` treats 429 as
   transient with exponential backoff, propagates on exhaustion; runner
   records the failure and continues. **Covered** (depth-of-backoff caveat,
   case R3).
4. Watermark `openrouter/<model>` → `RFC_MODEL_NAME` env override in
   `DbListener` (top precedence), raw id in `DEFAULT_MODEL`. **Covered.**

Verdict on intent: the diff addresses all four scope items of #507.
